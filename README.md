# QazaqType

Қазақ тілінде жылдам әрі сауатты теруге арналған интерактивті пернетақта жаттықтырғышы.

## Мүмкіндіктер

- Қазақ пернетақтасының толық раскладкасы
- Деңгейлерге бөлінген 20 сабақ
- Жылдамдық, дәлдік, қате және уақыт статистикасы
- Саусақ пен келесі пернені визуалды көрсету
- Абайдың қара сөздерімен жаттығу
- Тіркелмей қолданғанда нәтижелерді браузерде сақтау
- Email немесе Google арқылы жеке кабинетке кіру
- Прогресті Supabase бұлтымен құрылғылар арасында синхрондау
- Күнделікті оқу мақсаты және жеке статистика
- Мұғалім кабинеті: сынып, қосылу коды және сабақ тағайындау
- Оқушы кабинеті: сыныпқа кодпен қосылу және тапсырманы бастау

## Іске қосу

Node.js орнатылғаннан кейін:

```bash
pnpm install
pnpm dev
```

Сайт әдепкіде `http://localhost:5173` мекенжайында ашылады.

## Бұлттық база және аккаунттар

1. Supabase-та жаңа жоба жасаңыз.
2. SQL Editor ішінде [`supabase/schema.sql`](supabase/schema.sql) файлын толық орындаңыз.
3. `.env.example` файлын `.env.local` деп көшіріп, Supabase Project URL және anon key мәндерін енгізіңіз:

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

4. Supabase Authentication → URL Configuration бөлімінде жергілікті және өндірістік URL-дерді рұқсат етілген redirect URL тізіміне қосыңыз.
5. Vercel Production ортасына осы екі айнымалыны дәл сол атаулармен енгізіңіз.

Google арқылы кіру қажет болса, Supabase Authentication → Providers ішінен Google провайдерін қосыңыз. Email/құпиясөз арқылы кіру қосымша провайдерсіз жұмыс істейді.

Дерекқорда Row Level Security қосылған: оқушы тек өз нәтижесін, ал мұғалім тек өз сыныбына қосылған оқушылардың нәтижесін көре алады.
